# Outlaws Lite: A Minor DeCiv 2 Expansion Mod
For those who like the idea of the additional factions of "Outlaws of the Wastes" but *don't* like the other content in that mod, this one only contains the new factions/City-States and a handful of other components.

Cannot be used with DeCiv Redux; must be used with the "Deciv 2" fork.
